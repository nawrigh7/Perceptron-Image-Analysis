Naming scheme for error files:

listed in order as they appear in code for PgmValidator:

classM_1 = invalid name - class value
blass00_0 = invalid name - not "class"
class-1_-22 = negatives in name
class00_0 = empty file
class00_1 = invalid format
class01_1 = contains non-ints
class02_1 = invalid width
class03_1 = invalid height
class04_1 = invalid px
class05_1 = dims error
class06_1 = value too high
class07_1 = non pgm
